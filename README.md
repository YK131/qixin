# 栖心 Qixin

一款面向东大学子的 Python 桌面 Demo：把每日人文推送、四维情境歌单、诗意待办、随笔记录、情绪档案与学院新闻放进同一个低打扰空间。

![今日栖居](screenshots/01-home.png)

## 现在可以体验什么

- **毛玻璃界面**：暖白和鼠尾草绿的柔焦底图，搭配带细描边的半透明圆角卡片。首页突出诗句与心情记录，侧栏可直达六个主要页面。
- **滚动与点击**：滚动以 60 FPS 为调度目标，到达边界时平滑停下。点击后立即处理操作，同页数据刷新保留滚动位置。
- **页面显示**：在「数据与设置 → 页面显示」选择要显示的首页卡片、侧栏页面和歌单、日历、新闻的部分区块。调整会自动保存，也可以一键恢复全部区块。
- **无干扰人文组件**：独立置顶悬浮卡，点击换一句；包含原句、出处、通俗化哲学概念和释义，可拖动。
- **诗句与哲思扩容**：内置数百条公私领域经典诗句与哲思，覆盖变化、行动、孤独、疲惫、关系、成长等场景。每条都附有**现代释义**与一段**西方哲学视角**的对照解读；语料在启动时按固定种子打乱，不会总从同一句开始，界面上也不显示总条数。
- **九种基础情绪 + 自定义心情**：精神状态良好、美美得很、已老实、心流在线、摸鱼中、活人微死、淹没在作业海、无语、灵魂出窍；最多还可以添加 3 个自定义心情，名称与颜色会保存在 SQLite 中。旧版情绪记录会自动迁移。
- **随笔记录（富文本）**：日历右侧原来的「情绪分布」统计已替换为随笔面板。写随笔时选中任意文字，即可单独设置字号、加粗、斜体、字体与荧光高亮（暖黄/浅绿/浅粉/浅蓝，可清除）；格式随笔记持久化，重启仍在。
- **今日新闻**：自动抓取东南大学吴健雄学院官网与公众号文章，识别「导师交流」「人文讲座」，整理出导师/演讲人、时间、地点、名额与报名开放时间；检测到可抢选活动时首页侧栏提示并弹出发提醒，新闻页顶部固定一条「记得抢选」清单。
- **吃什么转盘**：桌宠右键菜单或左侧「今天吃什么」打开；早餐/午餐/晚餐/夜宵各 16 道不重复菜样，一次性全部画在同一张盘上。转盘改为更紧凑的尺寸（约屏幕短边的 56%），底部两个操作按钮放大成 52px 高的胶囊，更好点按；16 个扇区的菜名仍是「两行居中竖排」，按扇区弦长自动定字号，不压字、不截断。转盘停下后**中选扇区高亮、其余变暗**，并弹出一张「今天该吃……」的结果卡（可就吃这个，也可再转一次）。
- **可换装桌宠**：默认使用随项目提供的透明角色图；左键触发挥手与 Q 弹，右键更换形象。**上传任意格式图片（PNG/JPEG/WebP/BMP/GIF/TIFF…）都会自动抠出透明底**——纯色、渐变、四角不同色的「桌面照」都能处理，主体贴边或有软边时也尽量保留；万一抠失败会退回「原图 + 柔和投影」，不会给出空白。
- **可缩放窗口与全屏**：拖动窗口边缘即可拉长/缩小，页面会按新尺寸重新排版（宽度不足时自动从两栏降为单栏）；标题栏右侧的 ⛶ 按钮或 `F11` 可切换全屏，`Esc` 退出全屏。窗口尺寸会被记住，下次启动沿用。
- **字号与自适应排版**：基础字号整体调大（默认 120%），首页即可用 `A−/A＋` 在 90%–160% 间调节；字号变化时**文字、图标、圆点、间距与卡片同步缩放**，两栏布局在 124% 以上自动改为单栏，内容按实际文字高度重新排版，超出视口时纵向滚动（右下角提示「滚动查看更多」），不会出现文字挤压或跑出边框。
- **字体更换**：在「数据与设置」可上传 TTF/OTF/TTC 字体并立即切换或恢复默认，字号仍归首页控制。
- **自定义外观**：在「数据与设置」中可上传背景图和左上角图标，也可恢复默认毛玻璃背景与「栖」字图标。
- **四维情境歌单（含流行/摇滚/古典）**：曲库扩到 34 首、15 种取向，除钢琴、Lo-fi、City Pop、后摇等器乐外，还加入周杰伦《晴天》《七里香》、方大同《Love Song》《特别的人》、陶喆《普通朋友》《爱，很简单》、五月天《倔强》、Beyond《海阔天空》、朴树、陈奕迅、王菲，以及肖邦、贝多芬、久石让、坂本龙一。器乐仍可在本地合成 18 秒试听；真实歌曲受版权限制不在 Demo 内分发，点「平台试听」会打开网易云 / QQ 音乐的官方搜索页。卡片刻意把歌手写在副标题里，并按四维情境匹配。
- **诗意日程**：添加今日待办时自动匹配哲理寄语；支持完成、恢复和删除。
- **日历日程（多条 + 双击编辑）**：点击「＋ 日程」可添加日期、时间、名称和备注；日期格默认可显示 4 条日程（字号越大自动减少并显示「+N」），右侧详情卡列出更多条目。**双击任意日期格**会打开当天日程清单，可逐条编辑、删除或继续添加；在清单里点「编辑」会带着原内容打开编辑框，保存后立即同步回月历。
- **情绪日历**：按天记录心情、活动与天气；日期格用**整格淡色底 + 左侧实色条 + 心情名**表达当天状态，格子比旧版更大更亮，多段记录用圆点标出；点击回看、本周《情绪与哲思周报》。
- **日历双视图**：月视图与周视图自由切换，图例改为紧凑的单行色点，右侧统计改为规整的统计卡。
- **情绪清空**：日历页提供清空入口，执行前会明确提示并二次确认；只删除情绪记录，待办、随笔与设置保留。
- **AI 增强，而非依赖**：配置兼容 Chat Completions 的模型后，AI 可在候选曲库中二次校准，并改写周报；未配置时所有核心链路仍可运行。
- **本地隐私**：SQLite 保存在本机；AI 只接收主动选择的心情、活动、天气、时段标签，不发送任务原文与随笔正文。

## 桌宠快捷操作

- **专注计时**：右键桌宠选一条今日待办，开始 25 分钟专注。桌宠旁有进度环，结束后可休息 5 分钟、继续专注或标记待办完成。
- **随手记一下**：使用右键菜单或 Ctrl+Alt+N，按回车存入首页的「待办收件箱」。可从收件箱移入今日待办。Windows 支持系统级热键，其他系统在栖心窗口内使用该快捷键。
- **下一件事**：在桌宠上停留片刻查看最近日程。有具体时间的日程在开始前 10 分钟内轻提醒一次。也可从右键菜单主动查看。
- **免打扰**：专注期间不弹日程提醒，可手动暂停提醒一小时。Windows 检测到前台应用全屏时临时收起桌宠，退出全屏后恢复。

## 直接运行

Windows 当前环境可直接双击：

```text
run_demo.bat      # 带近一个月演示数据
run.bat           # 空白正式档案
```

也可以通过 Python 运行：

```powershell
python -m pip install -r requirements.txt
python -m qixin --demo
```

正式使用：

```powershell
python -m qixin
```

项目只需要 Python 3.10+ 与 Pillow。`run_demo.bat` 会依次寻找本机 Python、虚拟环境和当前 Codex 附带运行时；若找不到会给出提示。

## 演示流程

### 路径一：从清晨开始

1. 打开「今日栖居」，在底部的「阅读字号」里试试 `A＋`，观察卡片、图标与两栏排布一起变化。
2. 点击引文切换，再选择「美美得很 / 写论文」并记下此刻。
3. 在「今日待办」添加一项具体任务，观察自动附带的哲思寄语。「下一件事」会显示最近的日程，可以直接打开当天的日历。
4. 点击右下「去听一段属于此刻的声音」，进入歌单结果并播放。

### 路径二：两组四维情境对比

进入「数据与设置」，点击底部的「进入这段情境」：

| 场景 | 四维输入 | 预期方向 |
| --- | --- | --- |
| 晴天 · 美美得很 · 写论文 | 晴 + 明亮心情 + 上午/下午 | 温暖轻氛围、稀疏琴音、低 BPM |
| 阴天 · 活人微死 · 复习考试 | 阴 + 低电量 + 夜晚 | 雨夜爵士、慢速钢琴、稳定的低频铺底 |

### 路径三：随笔记录

1. 进入「情绪日历」，右侧「随笔记录」面板点「＋ 写一篇」。
2. 在编辑器里写几行字，选中其中一句，依次试 `B`、`I`、字号、字体下拉和荧光色块。
3. 保存后回到日历页，随笔摘要会出现在右侧面板；点「查看全部随笔」可进入整页视图。

### 路径四：今日新闻与抢选

1. 点击左侧「今日新闻」，首次进入会自动同步学院公众号（也可点「立即同步」）。
2. 顶部「记得抢选」列出报名尚未截止的活动，过期项目仍可在下方新闻列表查看。仅有开放日期、没有截止或活动日期时，提醒保留到开放当天结束。
3. 点「打开原文」可跳到公众号原文核对。
4. 在活动下点「报名时提醒我」，确认北京时间。提醒会保存在本机，可在「我的抢选提醒」取消。栖心运行时，到点会在桌宠旁弹出通知，可直接打开公告给出的报名页，或打开原文查看报名方式。桌宠隐藏时，通知出现在桌面右下角。专注、全屏或静音时会暂缓提醒，开放后最多补提醒 30 分钟，报名截止或活动开始后停止补提醒。

### 路径五：周报、桌宠与换装

1. 在「情绪日历」点击不同日期查看当天心情与日程，再点「打开《情绪与哲思周报》」；配置 AI 后可「AI 深度整理」。
2. 桌宠默认在屏幕右下角：左键触发挥手与 Q 弹，右键更换形象、调整大小、开关动画、打开吃什么或主程序。
3. 右键「更换桌宠形象…」随便选一张手机照片或网页图片（JPEG/PNG/WebP 都行），程序会自动去背景并替换形象。

### 路径六：吃什么

1. 打开左侧「今天吃什么」，等转盘停下：中选的那一格会高亮，其余变暗。
2. 弹出的「今天该吃……」小卡里可以点「就吃这个」，或「再转一次」。

## 可选服务配置

### AI

PowerShell 示例：

```powershell
$env:QIXIN_AI_API_KEY="你的密钥"
$env:QIXIN_AI_BASE_URL="https://api.openai.com/v1"
$env:QIXIN_AI_MODEL="gpt-4.1-mini"
python -m qixin --demo
```

也可沿用 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`。接口需兼容 `/chat/completions`。密钥只从环境变量读取，不会写入 SQLite。

也可以复制 `.env.example` 为项目目录下的 `.env` 后填写；栖心启动时会读取它，`.env` 已加入 `.gitignore`。

### 天气

默认通过 Open-Meteo 获取南京天气，无需天气密钥。可覆盖坐标：

```powershell
$env:QIXIN_CITY="南京"
$env:QIXIN_LAT="32.0603"
$env:QIXIN_LON="118.7969"
```

请求失败时界面会明确显示「示例」，不会把离线兜底数据伪装成实时天气。

### 今日新闻

新闻模块只访问两类公开页面，不需要登录：

1. 学院官网首页 `https://wjx.seu.edu.cn/`，按标题筛选「导师交流」「人文讲座」等条目；
2. 条目跳转后的公众号文章页 `https://mp.weixin.qq.com/s/...`，从正文中解析演讲人、时间、地点、名额与报名时间。

抓取在后台线程进行，带 15 秒超时与 6MB 单页上限，最多跟进 6 个详情页；30 分钟内复用缓存。任何网络异常都不会影响主界面：依次降级为「旧缓存 → 内置示例」，并在页面上注明来源状态。

已知限制（页面会如实呈现，不做猜测）：

- 部分「导师交流」的每场时间/地点以图片或表格排版，正文里没有文字时字段留空；
- 只扫描官网首页的近期条目，更早的文章不会回溯；
- 公众号若触发风控返回验证页，该条降级为「仅标题 + 原文链接」。

### 第三方音乐

第三方曲库涉及账号授权、版权和地区限制，因此 Demo 不抓取也不内置商业曲目。当前做法是：本地合成一段 18 秒的音乐化试听片段，同时为每首曲子配好**官方平台的搜索/歌单链接**（网易云音乐、QQ 音乐），点「打开歌单」即在浏览器里查看——不自建曲库、不写死会失效的歌单 ID。若你有授权 SDK，可把 `qixin/audio.py` 的 `AmbientPlayer` 换成平台播放器，标签与四维匹配逻辑可以保持不变。

平台搜索页会随关键词变化，首次点击时若平台要求登录，属于平台侧行为；`qixin/playlists.py` 里可以替换或增加平台适配。

  pages_music.py    情境歌单页（自适应布局）
  pages_calendar.py 情绪日历页（月/周视图 + 右侧随笔面板）
  pages_settings.py 数据与设置页（自适应布局）
  pages_today 逻辑位于 ui.py（_today_* 系列方法）
  notes.py       随笔存储、富文本 run 序列化与富文本编辑器
  news.py        今日新闻抓取、解析与缓存
  appearance.py  自定义背景与左上角图标处理
  floating.py    桌面轻语悬浮窗（自适应高度）
  pet.py         透明桌宠、动画、右键菜单与任何格式图片换装

  food_wheel.py  吃什么转盘、旋转动画、结果高亮与结果弹窗
  mood_editor.py 自定义心情与颜色选择
  schedule_editor.py 日历日程录入、当天日程清单与逐条编辑
  typography.py  用户字体注册与本地持久化
  quotes.py      典藏语句（由 data/*.jsonl 生成，含西方视角）
  tracks.py      音景 / 歌单数据与四维匹配
  playlists.py   外部平台歌单链接构造
  data/          quotes_*.jsonl 语料批次
  assets/        默认桌宠透明 PNG
  content.py     人文内容门面（情绪、活动、任务寄语）
  db.py          SQLite 情绪、任务、播放与设置记录
  services.py    天气、AI、周报与外部音乐适配
  audio.py       离线环境声合成与循环播放
  theme.py       视觉系统：配色、圆角、分层阴影、极光面板与抗锯齿胶囊

tools/

  export_legacy_quotes.py 把旧语料导出为 JSONL 并补齐西方视角
  capture_demo.py 自动生成页面截图（含随笔与今日新闻）
  capture_floating.py 生成桌面轻语窗预览
  capture_report.py 生成周报弹窗预览
  capture_food_wheel.py 生成吃什么转盘预览

## 交互与动效

毛玻璃由 Tk 画布上的半透明圆角表面与柔焦底图合成。默认底图和上传的背景都会预先处理并缓存。滚动期间减少悬停重绘，按钮保留轻微的颜色变化和按压反馈。

## 布局与字号是怎么做到不挤的

旧版把卡片和文字都写成固定坐标，字号一放大文字就会顶出卡片。新版改成「测量-再绘制」：

1. `layout.TextMeter` 用与画布完全一致的字号向 Tk 要真实行高与字宽，并按可用宽度模拟换行；
2. `layout.Block` 是一个游标：先用 `draw=False` 跑一遍得到内容高度，再把卡片画成这个高度，最后用 `draw=True` 跑第二遍真正落笔——同一份布局代码，不会出现「算的和画的不一致」；
3. 所有间距、圆点、图标半径都乘同一个字号系数（`theme.scaled`），所以图标和文字永远同步放大；
4. 页面宽度不足或字号超过 124% 时自动从两栏降为单栏，内容超过视口高度时开启纵向滚动，并在右下角提示。

窗口本身也是同一套逻辑的输入：拖动边缘或进入全屏时，侧栏、页眉与内容区三个画布会按新的窗口尺寸重新贴合，页眉为日期、天气、连接状态和全屏控件预留空间，标题过长时自动省略。

## 数据位置

正式档案默认位于：

```text
%LOCALAPPDATA%\Qixin\qixin.db
```

演示档案单独存放在：

```text
%LOCALAPPDATA%\Qixin\qixin-demo.db
```

在「数据与设置」中可以导出 JSON、打开数据目录或导出 Markdown 周报。

用户上传的桌宠图片会标准化后保存在：

```text
%LOCALAPPDATA%\Qixin\pet\custom.png
```

用户上传的字体会保存在：

```text
%LOCALAPPDATA%\Qixin\fonts\custom-<文件标识>.ttf
```

字体只注册到当前栖心进程，不修改系统字体目录。情绪清空只删除情绪打卡记录，待办、随笔、歌单和外观设置都会保留。

随笔保存在同一个 SQLite 的 `notes` 表中，正文以「格式片段」数组存成 JSON，因此字号、加粗、斜体、字体与高亮都能原样还原。

今日新闻缓存位于：

```text
%LOCALAPPDATA%\Qixin\news\news.json
```

自定义背景图和左上角图标保存在：

```text
%LOCALAPPDATA%\Qixin\appearance\
```
